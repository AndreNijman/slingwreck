## Scope — read this twice

This task is the **core only**: deterministic scalar helpers, body creation,
integration, the world container, and a bit-exact digest. **Do not write the
collision solver.** No SAT, no manifolds, no impulses, no sleeping. Those are the
next task and they will be added to this same file, so structure it to receive them:
leave clearly marked section banners in the order the step function will eventually
run (`integrate → broadphase → narrowphase → warmStart → solveVelocity →
integratePositions → solvePosition → damage → explosions → sleep → cull`), with the

The reason for this order is that the determinism test must run and pass **before**
the solver exists. If `(c, s)` rotation or the digest turns out not to be portable

integration, not later against 900 lines of solver.

## Determinism, the hard requirement

Inside `physics.js` the only permitted `Math` members are `sqrt`, `abs`, `min`,
`max`, `floor`, `ceil`, `round`, `sign`. Every other `Math.*` — especially `sin`,
`cos`, `atan2`, `pow`, `hypot`, `random` — is banned, along with `Date`,
`performance`, and every browser and Node global. `tools/check.mjs` enforces this and
will fail the build.

- **Rotation is stored as `(c, s)`, never as an angle.** Integrate with
  `nc = c - s*w*dt; ns = s + c*w*dt`, then normalise by `1 / sqrt(nc*nc + ns*ns)`.
  Arithmetic and one `sqrt`, both exactly specified by IEEE-754, therefore portable.
- Provide `fromAngle(radians)` as an **explicitly non-deterministic boundary helper**
  for callers outside the sim (the editor's 15° snap, the UI's aim vector). It may
  use `Math.cos`/`Math.sin`. Put it behind a loud comment saying it must never be
  called from inside a simulation step, and keep it in a clearly separated
  `// --- boundary helpers, not sim-safe ---` section at the bottom of the file so a
  reader cannot mistake it for core.
  Since `tools/check.mjs` bans `Math.cos` file-wide, instead export
  `fromDegrees(deg)` implemented as a **lookup table of the 24 exact 15° steps**
  written out as literal cosine and sine pairs to full double precision. That covers
  every rotation the editor can produce, needs no trigonometry at all, and means the
  ban stays absolute with no exemption. Free rotation with `Shift` in the editor
  passes a unit vector in directly, so it needs no helper.
- Randomness: export `rng(seed)` returning a closure over xorshift32 state, yielding
  a double in `[0, 1)`. Use `>>> 0` and integer ops only. Also export `rngInt(r, n)`.

## Required exports and shapes

```js
export function makeWorld(opts)  // { gravity, bodies: [], nextId, time, ... } from TUNE
export function addBody(world, def)   // returns the body
export function removeBody(world, body)
export function step(world, dt)       // dt defaults to TUNE.step
export function digest(world)         // see below
export function rng(seed)
export function rngInt(r, n)
export function fromDegrees(deg)      // -> { c, s } from the 24-entry table
```

A body is a **flat object with a fixed shape**, created once and never given new
properties afterwards — a hidden-class change in the hot loop is the difference
between 120 bodies at 60 Hz and 120 bodies at 30 Hz. Fields, all present on every
body even when unused:

`id, kind ('box'|'circle'|'tri'), shape, mat, hw, hh, r, vx0..vx3/vy0..vy3` — no,
use a single `verts` Float64Array of local-space `x,y` pairs for polygons (empty for
circles) — plus
`x, y, c, s, vx, vy, av (angular velocity), im (inverse mass), ii (inverse inertia),
fric, rest, isStatic, isAsleep, sleepTimer, hp, maxHp, tag, dead`.

Mass comes from `shape.area * material.density`. Inertia for a box is
`m * (w*w + h*h) / 12`, for a circle `m * r*r / 2`, for the triangle use the correct
formula for a right triangle about its centroid and show the derivation in a comment.
Static bodies get `im = 0, ii = 0`.

`def` accepts `{ shape, mat, x, y, c, s, isStatic, tag, hpScale }` where `shape` is a
`SHAPES` id or a `{ kind, w, h, r, area }` literal, and `mat` is a `MATERIALS` id or
a literal. Derive everything else.

## The digest — get this exactly right

```js
export function digest(world)  // -> 8-character lowercase hex string
```

It must hash the **raw IEEE-754 bit patterns** of every body's `x, y, c, s, vx, vy,
av`, in ascending `id` order, using FNV-1a over the two `Uint32` halves of each
double via a shared `DataView` on an `ArrayBuffer(8)`.

Do **not** round, format, or `toFixed` the values first. The entire purpose of this
function is to detect a difference in the last bit, and stringifying a double throws
that away — a digest built from `toFixed(6)` would report success on exactly the
failure this test exists to find. Put that reasoning in a comment.

## tools/determinism-test.mjs

Runs one fixed scenario and compares digests across JavaScript engines.

The scenario (put it in an exported function in the test file, not in `physics.js`,
so the test owns it): seeded `rng(1337)`, 40 bodies of mixed shapes and materials
dropped from pseudo-random positions and given pseudo-random initial velocities and
spins, stepped 1800 times, taking a digest every 300 steps — 6 digests plus a final
one. Use only `rng` for the randomness so the scenario itself is reproducible.

Engines:

1. **Node** — import `physics.js` directly. Always runs.
2. **Chromium, Firefox, WebKit** — via `@playwright/test`. Start a minimal static
   file server from Node's `http` module on an ephemeral port serving the repository
   root, `page.goto` a generated blank page on that origin, and
   `page.evaluate` an `await import('/physics.js')` plus the scenario. Serving over
   http avoids the `file://` module CORS problem. Shut the server down in a `finally`.

Report a table of engine against the 7 digests, and **fail loudly and specifically**
on the first differing checkpoint, naming the two engines, the step number, and the
body whose values diverge first — a bare "digests differ" is useless for fixing it,
so include a per-body comparison at the first bad checkpoint.

Exit non-zero unless all four engines agree. If Playwright or its browsers are not
installed, print clearly which engines were skipped and exit **non-zero**, unless
`SKIP_BROWSERS=1` is set, in which case exit zero with a warning. The P1 gate runs it
without that variable.
